# Roadmap

Forward-looking intentions that are decided in direction but not yet scheduled.
Nothing here changes a standing rule until the work actually starts, at which
point it gets its own plan with acceptance criteria.

- **Codex as a second wrapped harness.** arcforge currently targets Claude Code
  only. The owner's long-term goal is to wrap both Claude Code and Codex. The
  architecture already keeps this cheap — skills are self-contained markdown
  plus a bare CLI on PATH — so the work, when scheduled, is packaging plus
  spike verification of Codex's discovery and invocation mechanics, not a
  redesign. Until then, "Claude Code only" statements in the rules describe the
  present, not a permanent decision.
